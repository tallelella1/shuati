# 初版实施

1. 验证固定模板的整卷解析、题号和答案校验，用仓库内的自制样卷覆盖 90 题场景。
2. 实现本地素材导入、题目版本、练习记录和模考状态，验证重复导入与恢复。
3. 接上 Obsidian 导入、作答、收藏、错题和成绩界面，打包到隔离 vault 验证。
4. 提交插件源文件和可手动安装的产物，核对 GitHub 的提交。

## 题库管理

- 「试卷 → 管理题库」先列出已导入的试卷，再对选中的试卷提供重命名、重定位和删除。「返回题库选择」可重新挑选其它题库。重导同一笔记时沿用自定义名称。删除清理该题库的所有题目版本、进度和相关作答，混合记录仅移除该题库的题目。
- 在 Obsidian 中移动源笔记、图片或文件夹会更新存档路径。若在外部移动题库，可选择库内的新笔记；插件校验题目、解析和图片对应关系，并保留题目 ID 与作答历史。手动重定位要求图片保留原文件名。
- Windows 隔离库实测通过重命名、选笔记重定位、附件改名后渲染、取消删除和确认删除。当前库已替换 `.obsidian/plugins/shuati/` 中的 `main.js`、`styles.css`，部署时核对 `data.json` 的 SHA-256 一致。
