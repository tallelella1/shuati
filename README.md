# 刷题 Shuati

在 Obsidian 里把本地 Markdown 题库导入成试卷。支持单选、多选和判断题，可逐题练习、限时模考、收藏和重刷错题。作答和成绩保存在当前库，练习无需联网。

## 安装 v0.1.0

1. 解压 [安装包](dist/shuati-0.1.0.zip)，将其中的 `shuati` 文件夹复制到目标库的 `.obsidian/plugins/`。确认 `manifest.json`、`main.js` 和 `styles.css` 都直接位于 `.obsidian/plugins/shuati/` 中。
2. 重启 Obsidian。在「设置 → 第三方插件」中启用「刷题 Shuati」。如果该库开启了安全模式，需要允许加载第三方插件。
3. 把解压得到的 `刷题样卷` 整个文件夹复制到库内。打开其中的 `样卷.md`，在命令面板运行「导入当前笔记为试卷」，然后确认导入。
4. 点击左侧的刷题图标，或运行「打开刷题」。选择「开始练习」或「整卷模考」。限时留空即可不限时，未完成的作答可从「继续作答」恢复，也可以点记录旁的「删除」并确认。普通练习时，在题目下方点「答题卡」并选择题号即可跳转。

已在 Windows 上的 Obsidian 1.12.7 验收。

## 自建试卷

用一级标题写卷名，用二级标题写每道题。题号可以不连续，但同卷内不能重复。下面是一个最小示例。

```markdown
# 数据练习

## 7 · 资料分析 · 单选
40 增加到 60，增加量是多少？

- A. 20
- B. 30
答案：A
解析：60 − 40 = 20。
```

- 多选题的题型填写 `多选`，答案可写作 `答案：AB`。只有选项全部匹配才判对。
- 判断题的题型填写 `判断`，选项用 `T` 和 `F`，答案也用对应的字母。
- 题干、选项和解析可使用 Markdown 表格及库内图片。用 `![[材料笔记]]` 嵌入共享材料，用 `![[附件.png]]` 嵌入图片。保留库内附件，刷题时仍会加载它们。图表样例见 [样卷](examples/刷题样卷/样卷.md)。
- 作答记录保存在 `.obsidian/plugins/shuati/data.json`。更新时替换插件的三个安装文件即可，保留 `data.json`。

## 本地开发

```sh
npm ci
npm run verify
```

构建在仓库根目录生成 `main.js`。测试覆盖固定模板解析、本地附件校验、作答存档和错题规则。
